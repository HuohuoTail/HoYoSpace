## 使用方法

### 安装

1. 打开无名杀，点击菜单栏的“选项”-“扩展”-“制作扩展”，扩展名输入“忽悠宇宙”，其他不作修改，直接点击确定。（这一步是为了给游戏内注册一个扩展的名额，相当于提前占了个位置，接下来就是让这个位置坐上“人”）
2. 在无名杀 `extension` 目录下找到刚刚创建的 `忽悠宇宙` 文件夹，打开后发现其中有 `extension.js` 文件。（这些东西就是游戏自动生成的“空座位”）
3. 下载《忽悠宇宙》扩展包，打开压缩包，直到界面中出现有名为 `extension.js` 的文件夹，这里面的就是扩展的内容。（我们需要把这些真正的扩展内容取代刚刚游戏创建的“空座位”）
4. 将上一步中压缩包里的文件全部复制并粘贴至无名杀目录 `忽悠宇宙` 文件夹内，同名文件全部覆盖替换（如果没有询问“是否覆盖”等相关提示，请查看复制地址是否有误）。
5. 重启游戏。
6. 打开游戏后如果没有显示武将，可以前往“选项”-“武将”找到hoyoSpace菜单，点击后开启武将包。
